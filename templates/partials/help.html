Help center

Quick guidance for the CVTS operations dashboard

Loading live data

Use Overview for operational metrics. Jobs, Customers, and Sites load directly from Synchroteam when the API connection is configured.

Finding records

Customers and Sites include search controls for filtering by name or ID. Jobs can be loaded by entering a Synchroteam job ID.

Connection issues

Check the local environment configuration and confirm the Synchroteam username, password, and list endpoints are available.

Reports

Use Download report from the Overview page to print or save the current operational view.
